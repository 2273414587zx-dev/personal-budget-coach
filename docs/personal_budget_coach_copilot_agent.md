3. 直接用自然语言描述："帮我创建一个 Personal Budget Coach 智能体……（收入/支出规则）"

## 主题边界（2026-10-04 已设置并验证生效）

**设置内容**（两步）：
1. **指令中加入"范围边界"（最高优先级）**：只回答与个人预算、收入、支出、储蓄率、债务还款和支出阈值直接相关的问题；无关请求不提供任何信息；越界时只回复"这个问题超出了个人预算教练的范围。请询问收入、支出、储蓄或预算规划相关问题。"；混合问题只回答预算部分。
2. **关闭 Web 搜索（关键动作）**：配置页 → 工作内容 → Web 搜索开关关闭。之前天气问题被回答是因为 Agent 调用 msn 搜索；关闭后无关问题无法联网作答，只能遵守边界。
