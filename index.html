健康预算规则

住房 Housing
≤ 月收入的 30%
债务还款 Debt
≤ 月收入的 20%
吃饭 Food
≤ 月收入的 15%
交通 Transportation
≤ 月收入的 15%
其他 Other
每类 ≤ 10%，目标储蓄率 ≥ 10%

三档结论： EMERGENCY 紧急（储蓄率 < 0%） AGGRESSIVE CUTS 需要削减（0%–10%） OPTIMIZATION 优化建议（≥ 10%）

实测结果（2026-10-04，全部通过）

测试输入Agent 回复
中文整句分析 我月收入 $4,000，房租 $1,500，吃饭 $800，交通 $350，其他 $500。请分析我的预算。 储蓄率 21.25% → OPTIMIZATION；房租超 $300、吃饭超 $200、其他超 $100；总支出 $3,150、结余 $850；建议先把吃饭降到 $600
中文多轮追问 我存的钱够吗？ 记住之前数据，21.25% > 10% 健康线；应急基金建议 3–6 个月（$8,000–$16,000）
英文提问 How much should I spend on rent if I earn $5000 a month? 推荐 ≤ $1,500（30%），附 $1,250/$1,500/$1,750/$2,000 对照表与 >40% 风险提示
主题边界 ✅ 今天天气怎么样？ 拒绝：“这个问题超出了个人预算教练的范围。请询问收入、支出、储蓄或预算规划相关问题。”

Agent 用代码解释器执行可复现计算；回答自动跟随用户语言（中文提问中文答、英文提问英文答）。

第二个 Agent · 账单省钱

Bill Saver 账单省钱助手

上传账单（CSV / PDF / 图片）或一句话说出支出，自动分类分析、找出浪费项、给出按优先级排序的省钱方案（含每月可省金额与新的储蓄率）。中英双语。也是 BSU Economics 课程作业演示。

打开 Bill Saver 开始对话

实测（2026-10-04）：中文账单 “工资 $3,500 / 房租 $1,200 / 外卖 $400 / 购物 $350 / 订阅 $30 / 电费 $80 / 其他 $200” → 分类占比表 + 优先级（购物→外卖→订阅→其他）+ 月省 $300 方案，储蓄率 35%→44%；英文 “How can I save $100 more each month?” → 英文回答，给出动订阅 / 只改外卖购物两套方案。

主题边界（已设置）

  • 只回答与个人预算、收入、支出、储蓄率、债务还款和支出阈值直接相关的问题。
  • 无关请求（天气、新闻、写作、闲聊等）不提供任何信息，礼貌拒绝并引导回到预算主题。
  • 混合问题时只回答预算相关部分，并说明其余部分超出范围。
  • 已关闭 Web 搜索，Agent 无法联网查询无关内容。
